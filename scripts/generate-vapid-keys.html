Generate VAPID keys

This runs entirely in your browser — nothing is sent anywhere. It generates the two keys the school app needs for push notifications. Keep this tab open until you've copied both values into place.

Public key

Not secret. Paste this as vars.VAPID_PUBLIC_KEY in wrangler.jsonc (edit the file directly on GitHub, or locally, then commit/push).


Private key (keep secret)

Don't commit this anywhere. After your first deploy, go to your Worker in the Cloudflare dashboard → Settings → Variables and Secrets → Add → type Secret → name it VAPID_PRIVATE_JWK → paste this whole line as the value.
